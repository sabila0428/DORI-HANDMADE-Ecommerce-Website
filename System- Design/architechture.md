# System Architecture

## 1. Architecture Pattern

Modular Monolithic Architecture

## 2. Architectural Style

N-tier Architecture

## 3. Layers

- Presentation Layer: React + Vite
- Business Logic Layer: Node.js + Express
- Data Access Layer: Models and Repositories
- Database Layer: MongoDB Atlas

## 4. Backend Modules

- Authentication
- Products
- Cart
- Orders
- Payments
- Custom Orders

## 5. External Services

- Firebase Authentication
- Cloudinary
- Payment Gateway
- Redis (Future Integration)

## 6. Architecture Decision

We selected a Modular Monolithic Architecture
because the initial application does not require
the operational complexity of microservices.
